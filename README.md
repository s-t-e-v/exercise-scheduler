# Exercise Scheduler

Exercise Scheduler is a local-first learning tool that helps learners systematically revisit textbook exercises through spaced repetition.

The initial target is Arabic textbook exercises from the Zad curriculum.

Learners solve exercises outside the app using their textbook, then self-evaluate their performance to schedule future reviews.

## Current Goals

V0 focuses on validating the core repetition workflow:

* exercise scheduling
* self-evaluation
* daily review queue
* spaced repetition logic

The project intentionally avoids unnecessary complexity and gamification in its early stages.

## Tech Stack

* Next.js
* Tailwind CSS
* Prisma
* PostgreSQL

## Current Status

The project is currently:

* local-first
* localhost-only
* single-user focused

## Core Workflow

1. Solve exercises from the textbook
2. Record self-evaluation
3. Update review schedule
4. Receive future review reminders
