The most common modern convention

Probably:
Conventional Commits.

Example:

feat: add exercise review scheduling
fix: correct next review interval bug
refactor: simplify scheduler service
docs: add repetition algorithm documentation
style: improve dashboard spacing
test: add scheduler unit tests

This is MUCH more professional than:

[ADD]
[FIX]
[WIP]

Avoid noisy tags.

Meaning of common prefixes
Prefix	Meaning
feat	new feature
fix	bug fix
refactor	internal code improvement
docs	documentation
chore	maintenance/config
test	tests
style	formatting/UI polish
BAD commit
fixed stuff

Useless.

GOOD commit
feat: implement daily exercise review queue

Clear.
Searchable.
Professional.
